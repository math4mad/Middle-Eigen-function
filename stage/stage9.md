# Stage9   "深层骨架=有害记忆" 能否站住脚？（L6 现象的稳健性检验）

## 背景（来自 stage5 深度验证）
Qwen2.5-0.5B + LoRA 上发现：只切**后 6 层** MLP `down_proj` 的 top-10% 奇异值，
dev 0.585（全场最佳）、final dev loss 1.01（全场最低），而切中 12 层（M12）显著掉到 0.505。
→ 命题：**预训练的"有害记忆"集中在深层 top 谱，删它给下游腾出泛化空间；中层 top 谱是任务刚需。**

但这是单 seed、RTE 单任务、dev 仅 277 条（±3% 噪声）得出的，必须做三重检验才算立住。

## 假设
1. **可复现**：TAIL6 > baseline 的增益在多个训练 seed 上同号。
2. **有边界**：效应随切除深度非单调——TAIL3≈TAIL6 > TAIL12（切过头会伤到中层刚需骨架）。
3. **随数据规模演化**：训练量 10%→30% 时，TAIL6 优势应**缩小**（数据多了，深层骨架从"记忆"变回"能力"）。
4. **随模型规模保持**：更大模型（Qwen2.5-1.5B, 28 层）的 TAIL7（≈后 25% 深度）复现同样增益 → 是规律不是 0.5B 偶然。

## 方法（4 个子实验，全部复用 `scripts/stage3_llm_lora.py`）
脚本已加好开关：`SEED`（训练种子）、`DATA_SEED`（固定=42 保证同一数据子集）、
`FRAC_TRAIN`（数据比例）、层组名 `TAILn/FRONTn/MIDn`（**层数自适应**，0.5B=24 层 / 1.5B=28 层）。

- **① 多 seed**：`SEED∈{1,2,3}` 各跑 baseline + TAIL6 → 看增益是否 3/4 同号、均值 > +0.03
- **② 边界**：TAIL3 / TAIL6 / TAIL12 → 验证非单调"倒 U"
- **③ 数据规模**：`FRAC_TRAIN=0.3` 跑 baseline / TAIL6 / TAIL12 → 看优势是否缩小
- **④ 模型规模**：Qwen2.5-1.5B（`BATCH=8`）跑 baseline / TAIL7 / TAIL14

判据与预期写进 `report/notes/qwen-deep.qmd` 第 6 节（把"限定"改写成"复验结论"）。
完整可执行命令见 **[`NEXT.md`](NEXT.md)**。

## 生物类比
深层 top 方向 ≈ **母语口音**（成年后固化、对二语任务是干扰）；中层 top 方向 ≈ **布洛卡区**（通用计算刚需，切了就不能造句）。
Stage5 的 L6/M12 对比正好对应：抹口音有益学外语，伤布洛卡区则废。

## 可行性（我的电脑：M1 Pro 16 核 GPU / 32GB / 393GB 空闲）
- 单组时长：0.5B ≈ 12–18 min，1.5B ≈ 25–35 min（bf16 未用，fp32 权重 ~3GB，LoRA 可训练参数 <1%）。
- 全套 ≈ 3–3.5 小时，可分两晚跑；MPS 偶发崩溃则重跑该组（`results_partial.json` 续用已有组）。
- 1.5B 权重已在后台从 ModelScope 下载（`Qwen/Qwen2.5-1.5B`，~3.1GB）。
- 显存兜底：若 1.5B fp32 OOM，加 `torch_dtype=bfloat16` 或 `BATCH=4` + 梯度累积。

## 结论判据（跑完填 → 2026-09-10，1h49m，11 组）
| 情形 | 结论 | 实测落点 |
|---|---|---|
| 4 项全过 | "深层骨架=有害记忆"作为可复现规律成立，可发进主报告 | — |
| 多 seed 过、规模/数据不过 | 是"小模型+小数据"现象，限定适用域 | **← 本档（偏半档）** |
| 多 seed 就翻车 | 归为 stage5 的噪声带假象，撤回该命题 | — |

逐项数据（详见 `outputs/stage9/summary.json`、报告页 `report/notes/l6-robustness.qmd`）：

1. **① 多 seed（同子集，SEED=42/1/2/3）** Δdev(best) = +0.058 / +0.007 / +0.032 / −0.014
   → 均值 **+0.021**（sd 0.031，t=1.33，p=0.28，95%CI [−0.004, +0.045]）。3/4 同号 ✅，均值 >+0.03 ❌
   → **未达判据**；stage5 的 +0.058 是 seed 42 专属。
2. **② 边界（seed42）** TAIL3 0.549 < **TAIL6 0.585** > TAIL12 0.549 → **倒 U 成立 ✅**（TAIL6 与 stage5 逐位一致 = 可复算）
3. **③ 规模（1.5B, 28 层）** baseline 0.661；TAIL7 **+0.014**（❌ 未达 +0.03）；TAIL14 **−0.051**（过头切除伤害随规模保持/更陡）
4. **④ 数据 30%（DATA_SEED=7）** baseline 0.661 → TAIL6 0.718，Δ **+0.058 = 10% 时的 Δ** → 优势**未缩小** ❌（"记忆→能力转化"预测被证伪；深层 top 谱在 3 倍数据下仍是净负担）
5. **合并 6 组配对**：5/6 为正；Δbest = **+0.026**（p=0.08, 95%CI [+0.005,+0.046]），Δ(末 3 epoch 均值) = **+0.031**（p=0.03）；Δ(final dev loss) = −0.116（p=0.38，仅 3/6 变好）→ dev loss 判据不稳

**修订后的命题（供 stage10 引用）**：深层 down_proj 的 top-10% 带**轻微净负担 ≈ +0.02~+0.03 dev（= 一个噪声带）**；
稳健的是"**中层刚需 / 切过头有害**"的不对称性，而不是"切深层有大幅提升"。
