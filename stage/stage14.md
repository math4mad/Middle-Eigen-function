# Stage 14 · 把注意力重参数化到 rank-1 原子层面（不只是"输入侧"）

## 提出这条的话（2026-09-10 11:30）

> "so I suppose attention mech can be rephrase params in model's rank-1 matrix level. not just input weights"

即：stage11 的 RS-LoRA 只把**输入侧**（A）换成随机子空间、输出侧（B）仍可学 —— 这是**不对称**的；
更自然的单位应该是模型自己的 **rank-1 原子** $\sigma_i u_i v_i^\top$，在原子层面重述参数。

## 为什么这条在注意力上格外成立（关键推导）

注意力打分是一个**双线性型**，不是单个矩阵：

$$\text{logit}(x,x') = x^\top\big(W_q^\top W_k\big)x'$$

把 $W_q=\sum_i \sigma^q_i u^q_i v^{q\top}_i$、$W_k=\sum_j \sigma^k_j u^k_j v^{k\top}_j$ 代入：

$$W_q^\top W_k=\sum_{i,j}\underbrace{\sigma^q_i\sigma^k_j\;\big(u^{q\top}_i u^k_j\big)}_{M_{ij}}\;v^q_i\,v^{k\top}_j$$

⇒ 注意力的**天然原子是"原子对" $(i,j)$**，其权重由两件事决定：
1. 两侧能量 $\sigma^q_i\sigma^k_j$（**数据科学坐标**）；
2. 输出方向的**对齐** $u^{q\top}_i u^{k}_j$（**功能坐标** —— 两个头内子空间是否真的接得上）。

这就是用户那句话的精确形式：**"按 rank-1 矩阵重述" 意味着参数应当挂在 $(i,j)$ 对（或单个原子的系数）上，
而不是挂在稠密权重矩阵的输入/输出半边。** 也正是 stage11 笔记里
"某些 rank1 的矩阵组合能张成一个单一能力非常强的线性空间"的代数版本。

## 实验设计（同一协议：Qwen2.5-0.5B + RTE 10% + 5 epochs，只动注意力 q/k/v/o）

把每个目标矩阵 $W=U\,\mathrm{diag}(\sigma)\,V^\top$ 的**方向全部冻结**，只留系数：

$$W(\delta)=U\,\mathrm{diag}(\sigma+\delta)\,V^\top,\qquad \delta\in\mathbb R^{m}\ \text{可学}$$

实现上就是"两端固定为 SVD 原子、中间一条对角线可学"：$y=\big((x V_m)\,(\sigma_m+\delta)\big)U_m^\top$。

| 组 | 基 | 可学量 | 每矩阵参数量（896×896） |
|---|---|---|---|
| `ATOM16 / ATOM64 / ATOM256 / ATOMfull` | **SVD 原子**（top-m） | 对角系数 δ | 16 / 64 / 256 / 896 |
| `RAND16 / RAND64 / RAND256` | **Haar 随机正交基**（同 m） | 对角系数 δ | 同上（**严格等容量**） |
| `lora8` | 两端都可学 | A、B | 46,080（现有控制组） |
| `ATOM64+NEW8` | 64 个 SVD 原子 + 8 个新随机方向 | δ + 新原子 | 64 + 8×1792 |

**判据（预注册）**
1. `ATOMm` ≫ `RANDm`（同 m，等容量）⇒ **σ 序 = 功能序的拙劣但有效的代理**，
   原子层面重参数化是"对的坐标"；反之（打平）⇒ 功能方向与大小无关，
   必须靠**损伤探针**（stage13 的 τ）才能定序 —— 用户"智能科学按功能方向排列"被正面支持。
2. `ATOM64`（64 个标量！比 LoRA r=8 少 **720 倍**参数）若达到 `lora8` 的 dev ⇒
   **微调主要是"重新加权已有原子"，不需要新方向**（呼应 r_eff≈2.3）。
3. `ATOM64+NEW8` 若显著 > `ATOM64` ⇒ 小样本微调**必须**引入谱外新方向（"入侵维度"真的存在）。
4. 同组在 MLP `down_proj` 上重复一遍（rel_perm 只有 0.47）⇒ 若那里 ATOM≈RAND 而注意力里 ATOM≫RAND，
   就得到**"坐标是否有效取决于矩阵类型"**的完整闭环 —— 这是本项目最想要的一张图。

## 成本
- 一次 SVD：注意力 96 个 896×896 ≈ 30 秒（MLP 若加入：48 个 4864×896 ≈ 3 分钟）。
- 单组训练 ≈ 4–5 分钟。最小可判组合：`ATOM64 / RAND64 / ATOMfull / ATOM64+NEW8` × 1 seed ≈ 20 分钟；
  加 seed 2 与 MLP 版 ≈ 40 分钟。仍只用 **Qwen2.5-0.5B**。
